# Padrão "Apoiar" dos projetos

Texto para colar no chat de cada projeto. Ele já sabe o que fazer com isto.

---

Coloque no site deste projeto a opção de apoiar, seguindo o meu padrão:

- Uma seção **"Apoie o NOME-DO-PROJETO"** no site, com o link **Apoiar** no menu.
- Texto curto: o projeto é grátis e vai continuar grátis, sem anúncio e sem plano pago; se ajudou, qualquer
  valor ajuda a manter o projeto andando.
- **Pix:** mostrar a chave `CHAVE-PIX` com um botão **Copiar**. A pessoa cola no app do banco e escolhe o
  valor que quiser. Se eu passar nome e cidade, gerar também o **QR Code Pix sem valor fixo** e o
  **Pix copia e cola**, no próprio navegador, sem serviço de fora.
- **GitHub Sponsors:** botão para `https://github.com/sponsors/kaikydev1-jpg`, só depois que o GitHub
  aprovar o perfil.
- No repositório, o arquivo `.github/FUNDING.yml` com o link da seção Apoiar do site
  (`custom: ["https://SITE/#apoiar"]`). Depois da aprovação do Sponsors, acrescentar `github: kaikydev1-jpg`.
- Em português e em inglês, funcionando bem no celular.
- Sem rastreador e sem coletar dados de quem apoia.
- A chave Pix é a aleatória: nunca CPF, telefone ou e-mail.
- Só publicar o site quando eu pedir.
